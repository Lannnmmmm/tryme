# Aan Maulana — Portfolio

A premium, editorial-style portfolio for research, operational improvement, automation, and digital experiments.

## Stack
- React + TypeScript + Vite
- Three.js with React Three Fiber / Drei for the interactive geometric hero
- GitHub Actions + GitHub Pages for static deployment

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Publish to GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push changes to `main` (the deployment workflow runs automatically).
4. Open **Actions** and wait for the workflow to finish.
5. The expected site URL is `https://lannnmmmm.github.io/tryme/`.
